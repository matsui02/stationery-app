### 本サービスの概要（700文字以内）

※ アプリの目的・概要・想定ユーザー・主な機能をまとめてください。
SNSで「#筆箱紹介」と検索して気になる文房具を見つけても、商品名が分からなかったり、使用感や他の商品との比較ができず、購入まで踏み切れないという課題があります。そこで、この課題を解決するために文房具好き向けの筆箱紹介アプリを作成しました。

このアプリでは、ユーザーが自分の筆箱やお気に入りの1本を写真付きで投稿でき、お気に入りポイントを共有できます。また、レビュー機能を実装しており、価格帯や他ユーザーの評価を参考にしながら文房具を比較・検討できます。

さらに、コメント機能も用意しているため、投稿を見て気になった文房具の名前や詳細を気軽に質問することができます。これにより、SNSでは分かりにくかった情報をユーザー同士で補完できる仕組みを目指しました。

主なターゲットは20代の文房具好きな大学生で、文房具との出会いや共有をより楽しめるサービスを目指しています。

### テーブル詳細

#### users (ユーザー情報)

- id : ユーザーを一意に識別する主キー
- name : ユーザーの表示名 (山田太郎)
- email : ログイン認証用のメールアドレス / ユニーク制約 (sample@example.com)
- password_digest : bcryptでハッシュ化されたパスワードを保存するカラム (平文のパスワードは保存しない)
- created_at : レコード作成日時
- updated_at : レコード更新日時

### brandsテーブル

- id : ブランドを一意に識別する主キー
- name : ブランド名 (PILOT)

### categoriesテーブル

- id : カテゴリを一意に識別する主キー
- name : カテゴリ名 (シャーペン)

### itemsテーブル

- id : 商品を識別する主キー
- name : 商品名 (クルトガ、ジェットストリーム)
- price_range : 商品の価格帯
- brand_id : 商品のブランドを識別する外部キー
- category_id : 商品のカテゴリを識別する外部キー
- created_at : レコード作成日時
- updated_at : レコード更新日時

### pencil_casesテーブル

- id : 筆箱投稿を一意に識別する主キー
- user_id : 投稿者のユーザーを識別する外部キー
- title : 筆箱投稿のタイトル
- concept : 筆箱のコンセプト
- created_at : レコード作成日時
- updated_at : レコード更新日時

### favorite_postsテーブル

- id : お気に入りの1本の投稿を一意に識別する主キー
- user_id : 投稿者のユーザーを識別する外部キー
- item_id : 投稿で紹介する商品を識別する外部キー
- title : お気に入りの1本投稿のタイトル
- favorite_point : 商品のお気に入りポイントや魅力
- created_at : レコード作成日時
- updated_at : レコード更新日時

### followsテーブル

- id : フォロー関係を一意に識別する主キー
- follower_id : フォローする側のユーザーを識別する外部キー
- followed_id : フォローされる側のユーザーを識別する外部キー
- created_at : フォロー日時
- updated_at : レコード更新日時

### pencil_case_itemsテーブル

- id : 筆箱投稿と商品の関連を一意に識別する主キー
- pencil_case_id : 関連する筆箱投稿を識別する外部キー
- item_id : 関連する商品を識別する外部キー
- created_at : レコード作成日時
- updated_at : レコード更新日時

### pencil_case_likesテーブル

- id : 筆箱投稿へのいいねを一意に識別する主キー
- user_id : いいねしたユーザーを識別する外部キー
- pencil_case_id : いいねされた筆箱投稿を識別する外部キー
- created_at : いいね日時
- updated_at : レコード更新日時

### favorite_post_likesテーブル

- id : お気に入りの1本投稿へのいいねを一意に識別する主キー
- user_id : いいねしたユーザーを識別する外部キー
- favorite_post_id : いいねされたお気に入りの1本投稿を識別する外部キー
- created_at : いいね日時
- updated_at : レコード更新日時

### ER図の注意点

- [ ] 最新のER図スクリーンショットがPRに掲載されているか
- [ ] テーブル名は複数形になっているか
- [ ] カラムの型は記載されているか
- [ ] 外部キーは適切か
- [ ] リレーションは正しく描かれているか
- [ ] 多対多の関係になっていないか
- [ ] STIを使用していないか
- [ ] postsテーブルに post_name のような命名をしていないか
