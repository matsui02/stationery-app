### 本サービスの概要（700文字以内）

※ アプリの目的・概要・想定ユーザー・主な機能をまとめてください。
文房具好きな人がSNSで気になる文房具を見つけても、商品名やメーカー名が分からず、詳細を調べられないことがあります。また、写真だけではどのような文房具が使われているのか把握しづらく、実際に購入するまでのハードルが高いという課題があります。

さらに、他の人がどのような筆箱や文房具を使っているのかをまとめて見ることができるサービスが少なく、自分の筆箱を作る際の参考情報を得にくいという課題もあります。

そこで、これらの課題を解決するために文房具好き向けの筆箱紹介アプリを作成しました。

このアプリでは、ユーザーが自分の筆箱やお気に入りの文房具を写真付きで投稿し、使用している文房具の情報やこだわりを共有できます。また、投稿の一覧表示や検索機能により、気になる文房具や他のユーザーの筆箱を簡単に探すことができます。

検索機能では、商品名・ブランド名・カテゴリ・価格帯を条件として文房具を絞り込むことができるため、自分の興味や予算に合った文房具を効率よく見つけることができます。

さらに、いいね機能やフォロー機能を通じて、気になるユーザーの投稿を継続的に閲覧できるため、新しい文房具との出会いや文房具好き同士の交流を促進します。

主なターゲットは20代の文房具好きな大学生で、他の人の筆箱を参考にしたい人や、お気に入りの文房具を発信したい人を想定しています。

### MVPで実装する予定の機能

- 機能1 新規登録機能
- 機能2 ログイン機能
- 機能3 筆箱投稿CRUD機能
- 機能4 お気に入りの1本投稿CRUD機能
- 機能5 一覧機能
- 機能6 詳細機能
- 機能7 検索機能
- 機能8 プロフィール機能
- 機能9 ページネーション機能
- 機能10 画像投稿機能
- 機能11 いいね機能
- 機能12 フォロー機能
- 機能13 トップページ機能
  - ランキング表示
    - 「筆箱投稿」と「お気に入りの1本投稿」のタブを切り替えてランキングを表示
    -  いいね数をもとにランキングを集計
  - 新着投稿表示
    - 「筆箱投稿」「お気に入りの1本投稿」のタブを切り替えて表示
    - 投稿日時の新しい順に表示
  - おすすめユーザー表示
    - フォロワー数の多い順にユーザーを表示
- 機能14 OGP画像生成・SNSシェア機能
  - 筆箱投稿およびお気に入りの1本投稿の内容をもとにOGP画像を自動生成
  - XなどのSNSでURL共有時にOGP画像を表示
  - OGP画像をクリックすると投稿詳細ページへ遷移可能

### テーブル詳細

### users (ユーザー情報)

- id : ユーザーを一意に識別する主キー
- name : ユーザーの表示名 (山田太郎)
- email : ログイン認証用のメールアドレス / ユニーク制約 (sample@example.com)
- password_digest : bcryptでハッシュ化されたパスワードを保存するカラム (平文のパスワードは保存しない)
- bio :  ユーザーの自己紹介文
- created_at : レコード作成日時
- updated_at : レコード更新日時

### brandsテーブル

- id : ブランドを一意に識別する主キー
- name : ブランド名 (PILOT)

### categoriesテーブル

- id : カテゴリを一意に識別する主キー
- name : カテゴリ名 (シャーペン)

### itemsテーブル

- id : 商品を識別する主キー
- name : 商品名 (クルトガ、ジェットストリーム)
- price : 商品の価格 (円)
- brand_id : 商品のブランドを識別する外部キー
- category_id : 商品のカテゴリを識別する外部キー
- created_at : レコード作成日時
- updated_at : レコード更新日時

### pencil_casesテーブル

- id : 筆箱投稿を一意に識別する主キー
- user_id : 投稿者のユーザーを識別する外部キー
- title : 筆箱投稿のタイトル
- image : 筆箱画像(画像ファイルはActive Storageを利用して管理)
- concept : 筆箱のコンセプト
- created_at : レコード作成日時
- updated_at : レコード更新日時

※画像はカラムとして保持せず、Active Storageのhas_one_attached : imageを利用して関連付ける想定です。

### favorite_postsテーブル

- id : お気に入りの1本の投稿を一意に識別する主キー
- user_id : 投稿者のユーザーを識別する外部キー
- item_id : 投稿で紹介する商品を識別する外部キー
- title : お気に入りの1本投稿のタイトル
- image : お気に入りの1本の画像(画像ファイルはActive Storageを利用して管理)
- favorite_point : 商品のお気に入りポイントや魅力
- created_at : レコード作成日時
- updated_at : レコード更新日時

※画像はカラムとして保持せず、Active Storageのhas_one_attached : imageを利用して関連付ける想定です。

### followsテーブル

- id : フォロー関係を一意に識別する主キー
- follower_id : フォローする側のユーザーを識別する外部キー
- followed_id : フォローされる側のユーザーを識別する外部キー
- created_at : フォロー日時
- updated_at : レコード更新日時

※(follower_id, followed_id) の組み合わせにユニーク制約を設定する

### pencil_case_itemsテーブル

- id : 筆箱投稿と商品の関連を一意に識別する主キー
- pencil_case_id : 関連する筆箱投稿を識別する外部キー
- item_id : 関連する商品を識別する外部キー
- created_at : レコード作成日時
- updated_at : レコード更新日時

※(pencil_case_id, item_id) の組み合わせにユニーク制約を設定する

### pencil_case_likesテーブル

- id : 筆箱投稿へのいいねを一意に識別する主キー
- user_id : いいねしたユーザーを識別する外部キー
- pencil_case_id : いいねされた筆箱投稿を識別する外部キー
- created_at : いいね日時
- updated_at : レコード更新日時

※(user_id, pencil_case_id) の組み合わせにユニーク制約を設定する

### favorite_post_likesテーブル

- id : お気に入りの1本投稿へのいいねを一意に識別する主キー
- user_id : いいねしたユーザーを識別する外部キー
- favorite_post_id : いいねされたお気に入りの1本投稿を識別する外部キー
- created_at : いいね日時
- updated_at : レコード更新日時

※(user_id, favorite_post_id) の組み合わせにユニーク制約を設定する

### プロフィールページ
※プロフィール機能では、ユーザー名、メールアドレス、パスワード、自己紹介に加えて、プロフィール画像およびプロフィール背景画像の表示・編集を行う想定です。
プロフィール画像とプロフィール背景画像はusersテーブルのカラムとして保持させず、RailsのActive Storageを利用して管理します。(has_one_attached :avatar, has_one_attached :background_image)
プロフィール画面では、ユーザー名、自己紹介、プロフィール画像、プロフィール背景画像を表示します。
プロフィール編集画面では、ユーザー名、メールアドレス、パスワード、自己紹介、プロフィール画像、プロフィール背景画像の編集を可能にする予定です。自己紹介はプロフィール編集画面で入力・更新できるものとします。

### OGP画像生成機能
OGP画像は favorite_posts や pencil_cases のデータから生成される派生データであり、DBの主データではないためER図には含めない
